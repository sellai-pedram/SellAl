SellAI v13 - OpenRouter Vision

AI provider: OpenRouter (primary) with openrouter/free. OpenRouter's free router can select vision-capable free models.

Environment variables:
OPENROUTER_API_KEY=your-key
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
OPENROUTER_MODEL=openrouter/free

OpenAI variables are retained as an optional fallback.
Never put API keys in the browser or GitHub. Keep them in Render Environment Variables.
